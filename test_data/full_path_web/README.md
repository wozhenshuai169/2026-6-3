# Full-Path Web Asset Dataset

This directory is generated by `tools/download_full_path_web_assets.py`.
It keeps the same logical test cases as `test_data/full_path`, but uses downloaded public web assets.

Run:

```bash
python tools/download_full_path_web_assets.py
```
