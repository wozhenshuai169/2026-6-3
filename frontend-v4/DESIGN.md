# Aurelian Guide V4 - Studio Command

## Direction

Studio Command unifies the visitor, guide, assistant, knowledge, and operations surfaces into one calm premium product language. It uses an ink-colored operational rail, an ivory workspace, editorial Chinese serif headings, and restrained clay-orange actions.

## Principles

- Preserve every API call, state key, route, polling loop, and control from `frontend-v3`.
- Use typography, spacing, and dividers before adding containers or elevation.
- Keep operational states explicit: clay for action, sage for healthy/live, red for attention.
- Avoid decorative gradients, glass effects, nested cards, emoji icons, and novelty AI styling.
- Respect reduced-motion preferences and keyboard focus visibility.

## Structure

- `assets/css/studio-command.css`: shared visual system and page-specific responsive composition.
- `assets/js/studio-command.js`: non-destructive presentation enhancements and preview fixtures.
- Existing files under `assets/js/pages/`: unchanged business behavior copied from V3.
- `assets/references/studio-command.png`: selected Product Design visual target.
