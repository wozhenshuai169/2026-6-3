## 算法待完成项

### P0：检索可信度与数据闭环

1. 将 `type`、`audience`、`updatedAt`、`routeIds` 等 chunk 元数据写入 SQLite。

   当前 `seed_scenic_chunks()` 只保存 `spot_id`、`topic`、`source`、`content`。这会导致无法按游客画像、路线、时效性和安全等级过滤检索结果。

2. 用混合检索替换单一 FTS 短语检索。

   建议：中文分词/BM25 + 向量检索 + 当前景点过滤 + 交叉重排。现有“当前景点内容兜底”必须带阈值，避免无关问题仍附带当前位置引用。

3. 增加检索置信度、拒答和引用校验。

   最低要求：Top-1 分数低于阈值、来源过期、或证据互相冲突时不生成确定事实；回答中的每个关键事实必须有对应引用。

4. 将 `visitor_behavior_insights.json` 接入管理端统计接口。

   该数据只能服务于运营洞察、热门景点和停留时长分析，不能用于身份识别或公共频道个性化披露。

### P1：多模态、路线和实时数据

1. 识景接入真实多模态 Provider，并保留固定图库兜底。

   未知图必须返回“不确定 + 候选”，不能默认绑定某一景点；识别结果应带置信度和知识库引用。

2. 补齐拈花湾的景区区域、路线模板、图片库和讲解段落。

   当前已具备知识 chunk，但 `scenic_areas.json` 中拈花湾路线为空，无法形成完整导览体验。

3. 填充实时运营事件和路径图数据。

   `operation_events.json`、`path_nodes.json`、`path_edges.json` 目前为空；封路、天气、人流、无障碍和低体力路线无法形成真实决策依据。

4. 接入真实 ASR/TTS Provider 后保留失败降级。

   需要验证真实音频内容会改变识别文本；ASR 低置信度应追问；TTS 音频格式和响应声明必须一致。

### P2：评测与可运营性

1. 用新资料扩充盲测集。

   至少覆盖：灵山新增景点、拈花湾景点、历史文化深问、时效信息、未知知识、公共/私人分流和多轮续讲。

2. 记录检索候选、最终引用、置信度、拒答原因和用户反馈。

   这些数据用于计算引用命中率、拒答正确率、热门问题、低质量 chunk 和知识缺口。

3. 建立知识版本和增量导入机制。

   每次导入记录资料来源、导入时间、chunk 数量、覆盖景点、失败条目；支持回滚某一资料版本而不影响其他上传知识。

4. 增加知识冲突审查。

   同一景点出现不同票价、演出时间或参数时，标记冲突并优先使用后台最新公告或人工审核版本。

## 最终完成边界：比赛终验版

本项目从此按“可验证的比赛终验版”收束，不以覆盖所有景区、所有模型能力或生产级规模为目标。

### 必须完成后才能宣布算法完成

1. **知识库闭环**

   - `scenic_chunks.json`、SQLite FTS 和主后端问答使用同一份知识；
   - 至少支持灵山胜境的公共问答、引用返回和未知知识拒答；
   - 后台可上传 `pdf/docx/md/json/xlsx`，其中 Excel 只进入脱敏运营分析；
   - 已有资料包可通过 `build_public_knowledge.py` 重建，不能依赖手工编辑结果。

2. **算法主链路闭环**

   ```text
   文字/语音/图片输入
   -> 介入决策
   -> 知识检索或私人助理/路线推荐
   -> 有引用的回答或明确拒答
   -> 公共回答后的自然续讲
   -> 日志和评测记录
   ```

3. **最低可靠性边界**

   - 私人需求不进入公共频道；
   - 走失、身体不适、离队、封路等高风险场景通知团长；
   - 图片或知识低置信度不强行识别、不编造；
   - 票价、演出时间、天气、封路等时效信息明确以公告为准；
   - 新增和原有算法测试通过。

4. **可答辩的评测证据**

   - 至少 60 条固定评测样本；
   - 覆盖公共/私人分流、知识问答、未知拒答、续讲、低置信度语音、图片识景、风险升级、路线推荐；
   - 输出决策准确率、引用命中率、私人误广播次数、风险升级召回率、响应时延；
   - 明确测试集为项目内评测，不冒充线上真实准确率。

### 本版本明确不做

- 不训练或微调专用模型；
- 不做完整知识图谱、GraphRAG、多 Agent 自主规划；
- 不做全景区实时地图导航和高精定位；
- 不做全量 Excel 原始行为数据的实时分析；
- 不做实时多人自由语音、说话人分离或复杂户外降噪；
- 不做复杂 3D 数字人、口型同步或情绪语音；
- 不承诺所有景区的资料覆盖，只完成灵山胜境终验场景，拈花湾作为可展示扩展。
