# 演示视频拍摄方案

## 成片规格

- 时长：6 至 8 分钟；分辨率：1920 x 1080；帧率：30 fps；格式：MP4/H.264。
- 浏览器缩放 100%，系统显示缩放固定；关闭通知、书签栏和无关标签页。
- 手机端画面用浏览器设备模式 390 x 844 录制，外部套一层简洁手机边框即可，不遮挡应用内容。
- 人声单独录制并降噪，峰值控制在 -6 dB 左右；系统 TTS 音量低于旁白 6 至 10 dB。

## 拍摄准备

1. 运行 `start.bat`，确认自检通过和 `/health/ready` 返回就绪。
2. 准备一段清晰普通话音频：“灵山大佛有多高？”以及一张灵山大佛测试图片。
3. 清理数据库中的无关测试记录，预建一个导游房间和一条可演示运营事件。
4. 依次打开游客端、导游端、管理端、知识库、测试终端，固定标签页顺序。
5. 完整彩排一次并记录各外部 API 的平均等待时间，旁白为加载阶段留出余量。

## 剪辑规则

- 只加必要的章节标题和鼠标高亮，不用花哨转场。
- API 等待超过 4 秒可做 1.5 至 2 倍速，但保留开始与结果两个连续画面，避免像伪造响应。
- 密钥、完整管理员密码、Token、用户昵称和本机私人路径必须打码。
- 所有“实时”“准确”“完整”等表述必须与画面证据对应；路线距离明确标注为简化演示估算。
- 片尾保留 5 秒，显示项目目录、`start.bat` 和验收文档文件名。
