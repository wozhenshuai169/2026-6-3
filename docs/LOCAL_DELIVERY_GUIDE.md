# 灵山胜境本地交付与验收指南

## 1. 运行条件

- Windows 10/11；Python 3.10 或更高版本。
- 首次安装依赖和调用大模型、地图、ASR、TTS 时需要网络。
- 建议使用 Chrome 或 Edge，手机演示可在同一网络下通过电脑局域网地址访问；默认脚本仅绑定本机地址以减少暴露面。

## 2. 启动

在项目根目录双击 `start.bat`。首次启动会创建 `.venv`、安装依赖并执行自检。出现 `[PASS] Preflight completed` 后，浏览器打开 `http://127.0.0.1:8000/`。

端口冲突时运行：

```bat
start.bat 8010
```

## 3. 配置

复制 `.env.example` 为 `.env` 后填写凭据。不要把真实密钥放进演示文稿、截图、日志或 Git。启动自检只显示功能是否启用，不显示密钥内容。

管理员账号由 `ADMIN_USER_NAME` 和 `ADMIN_PASSWORD` 设置。正式演示前必须修改示例密码。SQLite 数据保存在 `data/app.db`，上传文件保存在 `uploads/`。

## 4. 推荐验收顺序

1. 打开游客端，选择灵山胜境路线并查看景点讲解。
2. 提问“灵山大佛有多高”，确认回答包含来源引用。
3. 录制或上传语音，验证 ASR、问答、TTS 和男性数字人口型切换。
4. 上传灵山景点图片，验证图片识景及低置信度兜底。
5. 打开导游端与管理端，验证房间协作、运营事件、知识库和反馈看板。
6. 将浏览器切换为 390 x 844 或手机访问，确认 9 个主要页面均可竖屏使用。

## 5. 已知边界

- 资料包行为 Excel 不是真实灵山运营数据，不用于客流预测或经营结论。
- 票价、演出时刻和开放状态不视为实时事实；项目原有的候选设施位置予以保留并可参与简化导航，但会提示以现场标识和工作人员说明为准。
- 本次完整交付目标是灵山胜境；拈花湾等原有扩展知识继续保留，不代表已完成与灵山同等级的路线和现场核验。
- 路线距离来自简化演示路径图，不具备园区测绘或无障碍通行证明；安全与应急场景优先服从现场人员。
- 本地单机版使用 SQLite 和进程内房间状态，只支持单 Worker，不是多机集群部署版本。
